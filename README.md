
# MateUABCS

Repositorio de materiales y herramientas producidas en el marco del taller **"El poder de la programación en los cursos de matemáticas"** (DDIE · UABCS).

Aquí se comparten los artefactos interactivos (código en p5.js, notebooks de Google Colab, etc.) diseñados por los profesores participantes para sus cursos de matemáticas.

---

## Si es tu primera vez usando GitHub

No necesitas saber usar Git para aprovechar este repositorio.

- **Para ver o descargar un material:** entra a la carpeta correspondiente, abre el archivo y usa el botón "Download raw file" o copia el contenido.
- **Para usar un artefacto (p5.js):** normalmente basta con abrir el archivo `.html` en tu navegador, o copiar el código a [editor.p5js.org](https://editor.p5js.org).
- **Para usar un notebook de Colab:** ábrelo directamente en Google Colab desde el enlace que aparezca en la carpeta.
- **Si quieres subir o modificar algo** y aún no te sientes cómodo con Git, no hay problema: en las sesiones del taller veremos cómo hacerlo paso a paso, o puedes compartir tu archivo con el instructor para que lo suba por ti.
